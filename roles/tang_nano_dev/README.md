
# Role Name

`tang-nano-dev`

Installs the open-source FPGA development toolchain for Gowin-based FPGA development boards, including the Sipeed Tang Nano series.

Installs YosysHQ OSS CAD Suite and configures USB access for openFPGALoader.

The role does not install an IDE, general development tools, or the proprietary Gowin IDE. It is not tied to a particular FPGA board; device selection and configuration are handled by individual FPGA projects.

## Requirements

- Linux x86-64.
- Ansible on the control machine.
- Internet access to download OSS CAD Suite from GitHub.

## Role Variables

| Variable | Default | Purpose |
|---|---|---|
| `tang_nano_dev_release` | `latest` | OSS CAD Suite GitHub release tag, or `latest` |
| `tang_nano_dev_install_dir` | `/opt` | Parent directory for the versioned installation |
| `tang_nano_dev_link` | `/opt/oss-cad-suite` | Stable symbolic link to the selected installation |
| `tang_nano_dev_archive_dir` | `/var/tmp` | Temporary download and extraction directory |
| `tang_nano_dev_install_udev_rules` | `true` | Install openFPGALoader udev rules and create the `plugdev` group |
| `tang_nano_dev_configure_path` | `true` | Configure the environment through `/etc/profile.d` |

## Dependencies

None.

## Installed Software

The OSS CAD Suite provides:

- Yosys
- nextpnr-himbaechel
- Apicula (including `gowin_pack`)
- Icarus Verilog
- Verilator
- GTKWave
- openFPGALoader

## USB Access and udev Rules

The role installs the upstream openFPGALoader udev rules file:

`files/99-openfpgaloader.rules`

This file is maintained in the openFPGALoader source repository:

https://github.com/trabucayre/openFPGALoader

The rules assign supported USB programming interfaces to the `plugdev` group. The role creates this group if necessary, but does not add any users to it.

### Obtaining the udev rules file

The rules file is not generated by this Ansible role. It is copied from the upstream openFPGALoader repository and committed to this role so that the installed rules are version-controlled.

From the root of the Ansible repository, run:

```sh
mkdir -p roles/tang-nano-dev/files

git clone --depth 1 \
    https://github.com/trabucayre/openFPGALoader.git \
    /tmp/openFPGALoader

git -C /tmp/openFPGALoader rev-parse HEAD

cp /tmp/openFPGALoader/99-openfpgaloader.rules \
    roles/tang-nano-dev/files/

rm -rf /tmp/openFPGALoader
```

The current imported version is:

- Upstream repository: `trabucayre/openFPGALoader`
- File: `99-openfpgaloader.rules`
- Imported commit: `2aafd90208dc8c3142fb617d2a91522513107c17`

When updating the rules in future, repeat these steps and update the recorded commit hash.

### Applying USB permissions

The udev rules assign supported devices to the `plugdev` group.

The role ensures that this group exists, but does not add users to it. Add each user who needs access to FPGA programming devices:

```sh
sudo usermod -aG plugdev USERNAME
```

The user must log out and back in for the new group membership to take effect.

Unplug and reconnect the FPGA board so that udev applies the rules.

Check group membership with:

```sh
id USERNAME
```

The udev rules also use `TAG+="uaccess"`, which can grant access to the active local desktop user through a device ACL. Group membership is still useful for users who need access independently of the active desktop session.

## Example Playbook

```yaml
---
- hosts: all
  become: true
  roles:
    - role: tang-nano-dev
```

The suite is installed in a version-specific directory under `/opt`, with `/opt/oss-cad-suite` maintained as a symbolic link to the selected version.

The `/etc/profile.d/oss-cad-suite.sh` file sources its environment script for login shells.

The current implementation targets Linux x86-64. It does not select a board or FPGA device: those choices belong in each FPGA project's build configuration.

The availability of a particular Gowin device or family in the open-source place-and-route and bitstream tools is separate from installing the tools. Check current Apicula and nextpnr device support before selecting a board.

## Verification

After running the playbook and starting a new login session, check the installed tools:

```sh
yosys -V
nextpnr-himbaechel --version
iverilog -V | head -1
verilator --version
gowin_pack --help | head -1
openFPGALoader --version
```

With a Tang Nano board connected, check detection with:

```sh
openFPGALoader --detect
```
